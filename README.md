# EagleEyes

A browser-based first-person shooter built with [Babylon.js](https://www.babylonjs.com/) and [Vite](https://vitejs.dev/).

## Getting started

```bash
npm install
npm run dev
```

Open the printed local URL in your browser, then click the canvas to lock the pointer and look around. Move with `W` `A` `S` `D`.

## Build

```bash
npm run build
npm run preview
```
